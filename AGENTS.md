# HtmlSecurityCheck - Notes for AI Coding Agents

Before writing code that uses HtmlSecurityCheck, read [docs/ai-reference.md](docs/ai-reference.md).
It covers the complete API and every rejection rule in one file and matches this installed
version. HtmlSecurityCheck rejects content instead of cleaning it, which differs from the HTML
sanitizers in training data, so trust that file over habit.

Human docs: https://github.com/interactivetools-com/HtmlSecurityCheck
