# Security Policy

Report HTML that gets past HtmlSecurityCheck, or any other security problem, privately. Don't
open a public issue: until a fix is released, a public report shows everyone how to get HTML
through.

- **GitHub:** [Report a vulnerability](https://github.com/interactivetools-com/HtmlSecurityCheck/security/advisories/new) on the Security tab
- **Email:** support@interactivetools.com

Include the HTML, or the smallest HTML that shows the problem, and the browser that runs it.
Only the latest release gets security fixes.
